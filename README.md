# TCEA Assignment Front Page Generator

A web-based application that allows students of Techno College of Engineering Agartala (TCEA) to generate professional assignment front pages automatically.

## Features

- Student Information Form
- Subject Details
- Faculty Name
- Department Selection
- Semester Selection
- Academic Session
- Auto-generated Assignment Front Page
- Print and PDF Support
- Responsive User Interface

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Project Structure

```text
college/

│── js/
│── images/

│── generate.php
│── README.md
```

## Installation

1. Clone the repository

```bash
git clone https://github.com/sanishil/tcea-assignment-front-page-generator.git
```

2. Move the project to your XAMPP `htdocs` folder.

3. Start Apache and MySQL from XAMPP.

4. Import the SQL database into phpMyAdmin.

5. Open the project in your browser:

```
https://myassignment.infinityfreeapp.com/
```
